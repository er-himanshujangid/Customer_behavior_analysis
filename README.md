# Customer Behavior Analysis

## 📌 Project Overview

Customer Behavior Analysis is an end-to-end Data Analytics project focused on understanding customer purchasing patterns, preferences, and behavior.

The project follows a complete analytics workflow, starting with raw data in Excel, followed by data cleaning and analysis using Python, business analysis using PostgreSQL and SQL, and interactive dashboard development using Power BI.

The objective is to transform raw customer data into meaningful insights that can support data-driven business decisions.

## 🛠️ Tools & Technologies

* **Excel** – Raw dataset and initial data source
* **Python** – Data cleaning and analysis
* **Pandas & NumPy** – Data manipulation and preprocessing
* **Jupyter Notebook** – Python analysis environment
* **PostgreSQL** – Database management
* **SQL** – Business analysis and customer behavior queries
* **Power BI** – Interactive dashboard and visualization

## 🔄 Project Workflow

### 1. Data Collection & Cleaning — Python

Imported the raw Excel dataset into Jupyter Notebook and performed data cleaning using Pandas and NumPy.

Key tasks included:

* Understanding the dataset structure
* Checking missing values
* Identifying and removing duplicates
* Handling inconsistent data
* Correcting data types
* Performing exploratory data analysis
* Analyzing customer and purchasing patterns

### 2. SQL Analysis — PostgreSQL

Loaded the cleaned dataset into PostgreSQL and used SQL to solve business-related questions.

Analysis included:

* Customer purchasing behavior
* Product and category performance
* Spending patterns
* Customer frequency
* Discount and purchase behavior
* Top-performing products/categories
* Customer-level metrics

### 3. Power BI Dashboard

Connected PostgreSQL with Power BI and developed an interactive dashboard to present key findings.

The dashboard includes:

* KPI cards
* Customer analysis
* Purchase analysis
* Product/category insights
* Interactive slicers and filters
* Business-focused visualizations

## 🎯 Project Objective

**Raw Excel Data → Python Cleaning → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Insights**

This project demonstrates practical skills in **Python, Pandas, NumPy, SQL, PostgreSQL, Excel, and Power BI**, while showcasing the complete data analytics lifecycle.
